## 🚀 How to Get Started

To unlock full development flexibility:

#### Install dependencies
npm install

#### Start local development server
npm run dev (http://localhost:4321/)

#### Build production files
npm run build

More documentation open `/documentation` page and Nordicia Astro documentation will guide you with detailed step by step information.
