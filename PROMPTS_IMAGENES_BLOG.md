# Prompts para Imágenes de Blog — Nuevos Posts

## Formato recomendado
- **Herramientas:** Midjourney v7, DALL-E 3, Leonardo AI o Adobe Firefly.
- **Ratio:** 3:2 horizontal (1200 × 800 px aprox).
- **Estilo:** Fotografía realista, luz natural dorada (golden hour), estética editorial de viajes.
- **Sin texto ni logotipos** en la imagen generada.

## Instrucciones para subir las imágenes

1. Genera las imágenes con tu herramienta preferida (Midjourney recomendado para calidad fotorealista).
2. Convierte a formato **WebP** o **PNG** para mejor compresión sin pérdida.
3. Optimiza tamaño: máximo **200 KB** por imagen usando TinyPNG o Squoosh.
4. Guarda en `public/images/` con los nombres exactos indicados arriba.
5. Verifica que la build incluya las imágenes: `npm run build` y revisa `dist/images/`.

### Notas por imagen
- Las 3 imágenes de habitación (ES, CA, EN, FR) son visualmente similares pero nombradas distinto para SEO local y no repetir rutas. Puedes usar la **misma imagen base** renombrada, o generar variaciones ligeras.
- Las de desayuno también son similares entre idiomas — puedes reutilizar con distinto nombre.
- La de pareja romántica es la más importante para diferenciarse del resto. Asegúrate de que sea cálida y evocadora.
